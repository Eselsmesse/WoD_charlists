# Данные каталога V20

Структурированный артефакт пайплайна SPEC-004: механические факты правил V20
в JSON. Загружаются командой:

```powershell
python backend/manage.py seed_v20
```

Команда **идемпотентна**: upsert по натуральным ключам (`(line, category, code)`
для трейтов, `(line, code)` для кланов/архетипов, `(line, generation)` для
поколений, `(line, key)` для правил создания). Повторный запуск не плодит дубли.

## Файлы

| Файл | Содержимое |
|------|-----------|
| `v20_gameline.json` | Линейка `vampire` |
| `v20_traits.json` | 9 атрибутов, 30 способностей, 18 дисциплин, 12 бэкграундов, 5 добродетелей |
| `v20_clans.json` | 13 кланов с клановыми дисциплинами и слабостями (своими словами) |
| `v20_archetypes.json` | 41 архетип (Nature/Demeanor) |
| `v20_generations.json` | Таблица поколений 13-е…4-е |
| `v20_creation_rules.json` | Числа создания: 7/5/3, 13/9/5, freebie и пр. (key/value) |

## Правила наполнения

- `code` — английский слаг (адресация в API), `name` — локализованное имя (RU).
- **Тексты не копируются из книг** (Dark Pack): `summary`/`weakness_summary` —
  краткий пересказ своими словами или пусто. Механические факты (названия,
  числа, состав дисциплин) хранить можно.
- У каждого файла есть поле `source` — оно пишется в `Model.source`.
- Записи создаются с `origin="parsed"`. **Владелец валидирует данные вручную**
  (в админке или по diff) и переводит в `origin="verified"`; повторный
  `seed_v20` проставленный `origin` не сбрасывает.
