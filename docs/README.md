# Документация проекта WoD Charlists

Сервис для составления, хранения и шеринга листов персонажей (чарников) по
**World of Darkness 20th Anniversary Edition** (V20), плюс ИИ-генерация квенты.

Эта папка — единый источник правды по проекту. Документы пишутся **до** кода,
чтобы любой исполнитель (человек или агент) мог взять задачу и сделать её без
дополнительного контекста.

## Зафиксированные решения (резюме)

1. **Линейки**: старт — только **Vampire: The Masquerade (V20)**. Модель данных
   проектируется обобщённой, чтобы позже добавить Werewolf / Mage / Hunter / Changeling.
2. **ИИ**: квента генерируется через **внешний LLM API + RAG** по базе лора.
   Собственное дообучение модели — отложенная цель, не на старте.
3. **Архитектура**: **Django REST Framework** (бэкенд-API) + **SPA** (отдельный фронтенд).
4. **Игровые данные**: **парсятся** из источников в фикстуры, затем **валидируются вручную** владельцем.

## Учебная цель

Проект — основа для освоения Django. Через DRF покрываются: ORM и миграции,
модели и связи, админка, сериализаторы, вьюсеты, роутеры, права доступа,
аутентификация, тесты, управление настройками и деплой. См. [01-architecture.md](01-architecture.md).

## Статус

Черновик v0.1 — план составлен, реализация не начата (есть только стартовый
Django-скелет: приложения `main` и `storage`, демо-вью, стартовые модели).
