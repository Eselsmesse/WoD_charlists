# SPEC-007: Теги и группы (комплектование)

> Статус: TODO · Фаза: 2 · Зависит от: SPEC-006

## Цель

Дать пользователю расставлять теги и комплектовать персонажей в группы
(партии / coterie / хроники) — киллер-фича №2.

## Контекст / ссылки

- [04-api-spec.md](../04-api-spec.md#теги-и-группы), [03-data-model.md](../03-data-model.md).

## Скоуп

**В работе:**
- `Tag` CRUD: `GET/POST /tags/`, `PATCH/DELETE /tags/{id}/` — только свои теги,
  уникальность имени в рамках владельца.
- Присвоение/снятие тега: `POST /characters/{id}/tags/` (тело: список тегов или
  add/remove).
- `CharacterGroup` CRUD: `GET/POST /groups/`, управление составом (`members`).
- Фильтрация персонажей по `?tag=` и `?group=` (использует SPEC-006).

**Не трогаем:**
- Расшаренные/общие теги между пользователями — бэклог.

## Критерии приёмки

- [ ] Пользователь создаёт теги, видит только свои; дубль имени → 400.
- [ ] Тег навешивается/снимается с персонажа; список персонажей фильтруется по тегу.
- [ ] Группа создаётся, в неё добавляются/удаляются персонажи владельца.
- [ ] Нельзя тегировать/группировать чужого персонажа (404).

## Заметки по реализации

- `Tag.characters` и `CharacterGroup.members` — M2M; ограничивать выбор
  персонажами текущего пользователя (валидация в сериализаторе).
- Цвет тега — опционально (`#RRGGBB`).

## Затрагиваемые файлы (ориентир)

- `characters/serializers.py`, `characters/views.py`, `characters/urls.py`

## Тесты

- `APITestCase`: CRUD тегов/групп, изоляция по владельцу, фильтрация, запрет на
  чужих персонажей.

## Definition of Done

Теги и группы работают, изолированы по владельцу, фильтры действуют, есть тесты.
