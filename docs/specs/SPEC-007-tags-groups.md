# SPEC-007: Теги и группы (комплектование)

> Статус: REVIEW · Фаза: 2 · Зависит от: SPEC-006

## Цель

Дать пользователю расставлять теги и комплектовать персонажей в группы
(партии / coterie / хроники) — киллер-фича №2.

## Контекст / ссылки

- [04-api-spec.md](../04-api-spec.md#теги-и-группы), [03-data-model.md](../03-data-model.md).

## Скоуп

**В работе:**
- `Tag` CRUD: `GET/POST /tags/`, `PATCH/DELETE /tags/{id}/` — только свои теги,
  уникальность имени в рамках владельца.
- Присвоение/снятие тега: `POST /characters/{id}/tags/` (тело: список тегов или
  add/remove).
- `CharacterGroup` CRUD: `GET/POST /groups/`, управление составом (`members`).
- Фильтрация персонажей по `?tag=` и `?group=` (использует SPEC-006).

**Не трогаем:**
- Расшаренные/общие теги между пользователями — бэклог.

## Критерии приёмки

- [x] Пользователь создаёт теги, видит только свои; дубль имени → 400.
- [x] Тег навешивается/снимается с персонажа; список персонажей фильтруется по тегу.
- [x] Группа создаётся, в неё добавляются/удаляются персонажи владельца.
- [x] Нельзя тегировать/группировать чужого персонажа (404).

## Заметки по реализации

- `Tag.characters` и `CharacterGroup.members` — M2M; ограничивать выбор
  персонажами текущего пользователя (валидация в сериализаторе).
- Цвет тега — опционально (`#RRGGBB`).

## Затрагиваемые файлы (ориентир)

- `characters/serializers.py`, `characters/views.py`, `characters/urls.py`

## Тесты

- `APITestCase`: CRUD тегов/групп, изоляция по владельцу, фильтрация, запрет на
  чужих персонажей.

## Definition of Done

Теги и группы работают, изолированы по владельцу, фильтры действуют, есть тесты.

## Итоги реализации (2026-06-12) — статус REVIEW (в стеке над SPEC-006)

- `TagViewSet` и `CharacterGroupViewSet` на общей базе `OwnedModelViewSet`
  (кверисет по owner → чужой id 404; `perform_create` ставит владельца).
- Уникальность имени тега в рамках владельца — `validate_name` (400 на дубль);
  у разных владельцев одинаковые имена допустимы.
- M2M `characters`/`members` — поле `OwnedCharactersField`, ограниченное
  персонажами текущего пользователя (чужой персонаж → 400).
- `POST /characters/{id}/tags/` — `{"add": [id], "remove": [id]}`, только свои
  теги; чужой персонаж → 404.
- Тесты: 10 новых (CRUD, изоляция, дубль, чужие персонажи/теги, фильтры
  ?tag=/?group=) — всего 60, OK.
