# Спеки задач

Одна спека = одна осмысленная, самодостаточная задача под исполнителя (человека
или агента). Спека пишется так, чтобы её можно было взять без дополнительного
контекста: цель, рамки, критерии приёмки, затрагиваемые файлы, тесты.

## Как пользоваться

1. Бери спеку с наименьшим номером из текущей фазы ([06-roadmap.md](../06-roadmap.md)).
2. Проверь раздел **Зависит от** — предыдущие должны быть закрыты.
3. Делай строго в рамках **Скоуп → В работе**; всё из **Скоуп → Не трогаем**
   откладывай (или заведи отдельную спеку).
4. Задача готова, когда выполнены все **Критерии приёмки** и проходят **Тесты**.

## Статусы

`TODO` · `IN PROGRESS` · `REVIEW` · `DONE` — проставляются в шапке спеки.
