# SPEC-008: Шеринг по ссылке

> Статус: TODO · Фаза: 2 · Зависит от: SPEC-006

## Цель

Дать возможность делиться чарником по публичной ссылке в режиме read-only и
сохранять чужой расшаренный чарник себе — киллер-фича №3.

## Контекст / ссылки

- [04-api-spec.md](../04-api-spec.md#шеринг-sharing), [03-data-model.md](../03-data-model.md).

## Скоуп

**В работе:**
- Приложение `sharing` с `ShareLink` (token UUID, `can_copy`, `expires_at`).
- `POST /characters/{id}/share/` (owner) — создать/получить ссылку, вернуть `token`.
- `DELETE /characters/{id}/share/{token}/` (owner) — отозвать.
- `GET /shared/{token}/` (AllowAny) — read-only чарник: только игровые данные,
  **без приватного** (без email владельца, без личных тегов/групп/заметок,
  не отдаём `owner`).
- `POST /shared/{token}/copy/` (auth) — если `can_copy`, создать копию у себя
  (переиспользовать `characters/{id}/copy/`-логику).

**Не трогаем:**
- Гранулярные права (комментарии, доступ ST к редактированию) — бэклог.
- Публичная галерея/поиск по расшаренным — бэклог.

## Критерии приёмки

- [ ] Владелец создаёт ссылку; неавторизованный открывает `GET /shared/{token}/`
      и видит чарник в режиме чтения.
- [ ] Ответ по токену не содержит приватных данных владельца.
- [ ] Невалидный/отозванный/просроченный токен → 404.
- [ ] `copy` создаёт независимую копию у текущего пользователя (если разрешено).
- [ ] Чужой не может отозвать/создать ссылку на не свой чарник.

## Заметки по реализации

- Токен — `UUIDField(unique)`, не последовательный id.
- Отдельный «публичный» сериализатор с белым списком полей (не переиспользовать
  owner-detail, чтобы случайно не утечь приватное).
- Проверка `expires_at` и активности ссылки в одном месте (queryset-хелпер).

## Затрагиваемые файлы (ориентир)

- `sharing/` (модель, сериализатор, вьюхи, urls), подключение в `config/urls`

## Тесты

- `APITestCase`: создание/отзыв ссылки, публичный доступ по токену, отсутствие
  приватных полей в ответе, 404 на невалидный/просроченный токен, copy.

## Definition of Done

Шеринг read-only и копирование работают, приватные данные не утекают, токены
безопасны, покрыто тестами.
