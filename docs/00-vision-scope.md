# 00. Видение и скоуп

## Проблема

Игроки в World of Darkness ведут листы персонажей в PDF, бумаге или таблицах.
Это неудобно: легко ошибиться в правилах создания, тяжело хранить много
персонажей, нечем делиться, и нет помощи в написании предыстории (квенты),
которая бы логично связывала характеристики персонажа с его историей.

## Целевые пользователи

- **Игрок** — ведёт несколько персонажей, хочет хранить, тегировать, делиться.
- **Рассказчик (ST)** — собирает партию (coterie), просматривает чарники игроков.
- *(Косвенно)* новичок, которому ИИ помогает осмыслить статы через историю.

## Цели (killer features)

1. **Аккаунт и хранилище.** Авторизация; все персонажи привязаны к аккаунту.
2. **Теги и комплектование.** Расстановка тегов, группировка персонажей
   (например, в партии / coterie / по хроникам).
3. **Шеринг.** Поделиться чарником по ссылке; режим «только чтение»; сохранение
   копии себе.
4. **ИИ-квента (главная фича).** Генерация художественной предыстории, которая
   *объясняет* статы персонажа (высокая Сила → бокс/уличные драки и т.п.),
   с учётом контекста города/хроники и лора WoD.

## Не-цели на старте (out of scope для MVP)

- Линейки кроме Vampire V20 (закладываем архитектурно, не реализуем).
- **Обратная задача** «история → статы» (очень сложная; отдельная веха позже).
- Собственное дообучение нейросети (сначала API + RAG; обучение — потом).
- Полноценная игровая логика бросков кубов / трекинг боя в реальном времени.
- Мобильные нативные приложения (только адаптивный веб).
- Маркетплейс / монетизация.

## Критерии успеха MVP

- Пользователь регистрируется, входит, создаёт корректный чарник вампира V20.
- Чарник сохраняется, редактируется (точки атрибутов/способностей), удаляется.
- Персонажи тегируются и фильтруются по тегам.
- Чарник шерится по ссылке в режиме чтения.
- По кнопке генерируется черновик квенты, осмысленно опирающийся на статы
  и выбранный город; результат можно сохранить и отредактировать.

## Принципы

- **Корректность правил важнее количества фич.** Лучше один безупречный чарник
  вампира, чем пять полусырых линеек.
- **Расширяемость.** Каждая сущность проектируется так, чтобы добавление новой
  линейки было наполнением данных, а не переписыванием кода.
- **Учебная ценность.** Решения выбираются с прицелом на освоение Django, но
  без переусложнения.

## Юридическая заметка

World of Darkness / Vampire: The Masquerade — собственность Paradox Interactive.
Фанатские проекты допускаются по **Dark Pack** (community content policy) при
соблюдении условий. Практические следствия для нас:

- Хранить **механические данные** (названия трейтов, числовые рейтинги, списки
  кланов/дисциплин) — это факты правил; **не копировать дословно** описания и
  большие куски текста из книг.
- Любые описательные тексты — **переписывать своими словами / суммировать**.
- Разместить дисклеймер Dark Pack, не использовать проект коммерчески без
  проверки условий. Подробнее — в [02-domain-v20.md](02-domain-v20.md#юридические-ограничения).
