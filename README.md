# WoD Charlists

Сервис для создания и хранения персонажей для вселенной "Мир Тьмы" (World of Darkness), редакция правил V20.

## Краткое описание

- Хранение и создание персонажей для WoD V20
- В будущем: генерация квенты (предыстории персонажа) с помощью нейросети на основе описания, характеристик или других параметров

## Быстрый старт

1. Установите зависимости (если требуется):
   ```powershell
   uv pip install -r requirements.txt
   ```
   или
   ```powershell
   pip install -r requirements.txt
   ```

2. Активируйте виртуальное окружение (если используется):
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. Запустите сервер Django из корня проекта:
   ```powershell
   python wod_charlists/manage.py runserver
   ```
   
   После этого проект будет доступен по адресу http://127.0.0.1:8000/
