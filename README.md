# WoD Charlists

Сервис для создания и хранения персонажей для вселенной "Мир Тьмы" (World of Darkness), редакция правил V20.

## Краткое описание

- Хранение и создание персонажей для WoD V20 (старт — линейка Vampire: The Masquerade)
- Аккаунты, теги и комплектование, шеринг чарников по ссылке
- Главная фича: генерация квенты (предыстории) через LLM API + RAG, объясняющей статы персонажа

> 📚 **План, архитектура и спеки задач — в [`docs/`](docs/README.md).** Это источник
> правды по проекту; начинать работу — оттуда. Контекст для агентов — в [`CLAUDE.md`](CLAUDE.md).

**Стек (решено):** Django + Django REST Framework (API) + SPA-фронтенд, JWT-аутентификация,
ИИ через внешний LLM API + RAG. Подробности и обоснования — в [docs/01-architecture.md](docs/01-architecture.md).

## Быстрый старт

1. Создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv .venv
   ./.venv/Scripts/Activate.ps1
   ```

2. Установите зависимости:

   ```powershell
   pip install -r backend/requirements/dev.txt
   ```

3. Создайте файл окружения (необязательно для dev — есть безопасные дефолты):

   ```powershell
   Copy-Item .env.example .env
   # при необходимости заполните значения в .env
   ```

4. Примените миграции и запустите сервер (из корня репозитория):

   ```powershell
   python backend/manage.py migrate
   python backend/manage.py runserver
   ```

   Проект будет доступен по адресу <http://127.0.0.1:8000/>

## Настройки и окружения

- Настройки разнесены: `backend/config/settings/{base,dev,prod}.py`.
- По умолчанию используется `config.settings.dev`; продакшен — `config.settings.prod`
  (через `DJANGO_SETTINGS_MODULE`).
- Переменные окружения читаются из `.env` в корне репозитория (см. [`.env.example`](.env.example)).
  В prod `DJANGO_SECRET_KEY` и `DJANGO_ALLOWED_HOSTS` обязательны — без них запуск
  падает с явной ошибкой.
