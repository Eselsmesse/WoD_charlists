# CLAUDE.md

Контекст проекта для агентских сессий. Держать кратким и актуальным.

## Что это

Веб-сервис для составления, хранения и шеринга листов персонажей (чарников) по
**World of Darkness 20th Anniversary (V20)**, на старте — линейка **Vampire: The
Masquerade**. Главная фича — ИИ-генерация квенты (предыстории), объясняющей статы
персонажа, через внешний LLM API + RAG.

Проект также учебный: цель владельца — освоить Django.

## Зафиксированные решения

- Старт — только V20/Vampire; модель данных обобщённая под другие линейки.
- **DRF (API) + SPA** (по умолчанию React+Vite+TS).
- **JWT**-аутентификация.
- ИИ: **внешний LLM API + RAG**, провайдер за абстракцией; своё обучение — позже.
- Игровые данные **парсятся** в фикстуры, затем владелец **валидирует вручную**.

## Текущее состояние

Django 5.2 проект в `backend/` (перенесён из `wod_charlists/` в SPEC-001):

- настройки разнесены: `backend/config/settings/{base,dev,prod}.py`, env через
  `.env` (см. `.env.example`); зависимости — `backend/requirements/{base,dev,prod}.txt`.
- приложения `main` (демо-презентация, шаблоны) и `storage` (стартовые модели
  `SystemDefinition`, `Character`) — **временные**, будут расщеплены на
  `rules` + `characters` и убраны (см. SPEC-003).
- DRF + JWT (simplejwt) + CORS настроены (SPEC-002): кастомный `accounts.User`
  (email-логин), `/api/v1/health/`. Фаза 0 закрыта.
- SQLite. **Ещё не сделано**: доменные модели/фикстуры (фаза 1), реальные
  эндпоинты auth/персонажей (фаза 2).

## Git-процесс

- Базовая ветка — **`dev`** (не `main`). Одна спека = одна ветка + MR в `dev`.
- Агент может коммитить самостоятельно.

## Команды (Windows / PowerShell)

```powershell
# venv
./.venv/Scripts/Activate.ps1

# зависимости
pip install -r backend/requirements/dev.txt

# запуск (из корня репозитория)
python backend/manage.py runserver
python backend/manage.py makemigrations
python backend/manage.py migrate
python backend/manage.py createsuperuser
python backend/manage.py test
```

## Конвенции

- Документация и пользовательские строки — на русском; идентификаторы кода,
  `code`-слаги трейтов/кланов — на английском.
- Числовые правила V20 (7/5/3, 13/9/5, freebie, поколения) — **данные в `rules`**,
  не в коде.
- `rules` = общие факты правил; `characters` = контент пользователя. Не смешивать.
- Секреты — только через env, не в коде. Не коммитить `.env`, `db.sqlite3`,
  `__pycache__`.
- Описания из книг WoD **не копировать дословно** (Dark Pack / авторские права) —
  переписывать своими словами; см. `docs/02-domain-v20.md`.
- Работать в рамках одной спеки; смежное — отдельной спекой/задачей.

## Рабочий процесс

1. Выбрать спеку из `docs/specs/` по текущей фазе, проверить «Зависит от».
2. Реализовать строго в рамках «Скоуп → В работе».
3. Закрыть «Критерии приёмки», прогнать тесты.
4. Обновить статус спеки и реестр в `docs/specs/README.md`.
